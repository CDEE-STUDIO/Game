# คู่มือพัฒนาต่อ

## หลักการ
- **สคริปต์ธรรมดาหลายไฟล์ ใช้ตัวแปร global ร่วมกัน** (ไม่ใช้ ES modules) เพื่อให้เปิดจาก `file://` ได้โดยไม่ต้องมีเซิร์ฟเวอร์ แต่ละไฟล์ขึ้นต้นด้วย `"use strict"`
- **ลำดับ `<script>` ใน `index.html` คือลำดับการพึ่งพา** — registry → config → util/dom → ... → render → biomes → main
- เนื้อหาที่ต่างกันตามโลก (ฉาก, มอนสเตอร์, บอส, กระสุน) ถูกแยกเป็น **content pack** ใน `js/biomes/<โลก>.js` แล้วลงทะเบียนเข้า registry ใน `js/core/registry.js` ตัวเกมหลักไม่รู้จักชื่อโลก/บอสเลย

## Registry (js/core/registry.js)
| ตัวแปร | ความหมาย |
|---|---|
| `ZONES` | ลำดับโลก (ตามลำดับโหลดไฟล์ biome) |
| `ZONE_NAME[id]` | ชื่อไทยที่ขึ้นป้าย "เขตใหม่" |
| `PAL[id]` | สีฉากโหมดสว่าง `l` / มืด `d` (โลกที่ไม่มี PAL จะใช้สีจาก tokens.css) |
| `KIND_BY_ZONE[id]` | `[มินิบอส, บอสใหญ่]` ของโลกนั้น |
| `KINDS[kind]` | ข้อมูลบอส (ดูตารางล่าง) |
| `ZONE_ART[id](a, P, dark)` | วาดฉากหลัง |
| `CREATURE_ART[id](o, w, h, air, fl)` | วาดมอนธรรมดาของโลกนั้น (พื้น + ลอย) |
| `BOSS_ART[kind](b, w, h, white, en)` | วาดบอส (จุดกำเนิดคือกึ่งกลางล่าง หันซ้าย) |
| `PROJ_ART[name](o, w, h)` | วาดของที่บอสขว้าง/เรียก |

## ฟิลด์ของ `KINDS[kind]`
| ฟิลด์ | หน้าที่ |
|---|---|
| `name`, `big` | ชื่อมินิบอส (ต่อท้าย Lv.) / ชื่อบอสใหญ่ (ถ้าไม่ใส่ `big` ใช้ `name`) |
| `w`, `h`, `ms` | ขนาด และตัวคูณขนาดตอนเป็นมินิบอส (ค่าเริ่มต้น 0.95) |
| `c1`, `c2` | สีหลัก/สีขอบ (ใช้กับแถบเลือด อนุภาค) |
| `proj: [ล่าง, บน, ตกจากฟ้า]` | ชื่อ `PROJ_ART` ของกระสุนแต่ละแบบ |
| `size: [w, h]` | ขนาดกล่องชนของกระสุน (ค่าเริ่มต้น 32×28) |
| `alternate: true` | สลับ บน/ล่าง ทุกครั้ง |
| `rainLabel` | ข้อความท่า "ฝน" ของบอสตัวนี้ |
| `pyr: true` | ได้ท่าซัมมอนปิรามิด (ดู `summon()` ใน game/boss.js) |
| `groundSummon: {proj, h}` | ช่องล่างใช้ของที่โผล่ขึ้นมาจากพื้นแทนกระสุน (เช่นหนวดหมึก) |
| `darkBar: true` | แถบเลือดใช้สี `c2` (กรณีสีหลักอ่อนเกินไป) |

ความแข็งแรง (HP, ความถี่โจมตี, ความเร็วกระสุน) มาจากลำดับบอส (`BOSSES` ใน data/bosses.js + `bossPower()`), ไม่ผูกกับโลก

## เพิ่มโลกใหม่ (เช่น ป่า)
1. คัดลอก `js/biomes/desert.js` เป็น `js/biomes/jungle.js`
2. เปลี่ยน id (`"jungle"`), ชื่อ (`ZONE_NAME`), สีใน `PAL.jungle`
3. เขียน `ZONE_ART.jungle`, `CREATURE_ART.jungle`, `BOSS_ART.<มินิ>`, `BOSS_ART.<ใหญ่>`, `PROJ_ART.<กระสุน>` และกำหนด `KINDS.<...>` / `KIND_BY_ZONE.jungle`
4. เพิ่ม `<script src="js/biomes/jungle.js"></script>` ใน `index.html` ก่อน `js/main.js` (ตำแหน่งในรายการ = ลำดับโลก)
5. รัน `python3 tests/smoke.py` — จะเรียกฟังก์ชันวาดทุกตัวเพื่อจับ error

## เพิ่มท่าโจมตีบอสแบบใหม่
ท่าทั้งหมดอยู่ใน `planAttack()` (game/boss.js): เลือกท่าตามน้ำหนัก → สร้างคิว `b.queue` ของ `{at, h|drop|pyr}` → `updateBoss()` ปล่อยตามเวลา ถ้าท่าใหม่ใช้ได้เฉพาะบอสบางตัว ให้เพิ่มฟิลด์ใน `KINDS` แล้วเช็กใน `planAttack()` แบบเดียวกับ `pyr`

## ปรับสมดุล
ทุกค่าอยู่ใน `js/config.js`: แรงโน้มถ่วง/แรงกระโดด, ความเร็วเริ่ม/สูงสุด, ราคาและเวลาพุ่ง, ความยาวโลก (`ZONE_LEN`), คะแนนมินิบอสตัวแรก/ช่วงห่าง

## สไปรต์ตัวละคร
- เฟรมทั้งหมดอยู่บนผืนผ้าใบขนาดเท่ากัน (`FW`×`FH` ใน `js/assets.js`) เท้าอยู่แถว `FBASE` ตัวอยู่กึ่งกลางคอลัมน์ `FCX` หันซ้าย (เกมกลับด้านให้เอง)
- เปลี่ยนภาพ = แทนที่ไฟล์ PNG ชื่อเดิมใน `assets/sprites/` ถ้าขนาดต่างจากเดิมให้แก้ค่าใน `assets.js`
- เฟรมกระโดดแมปตามช่วงการกระโดดใน `drawPlayer()` (render/player.js) ด้วยชื่อ `F_PUSH`, `F_RISE`, `F_APEX`, `F_FALL`, `F_TOES`, `F_LAND`, ท่าก้มใช้ `F_CROUCH`

## สี / ธีม
แก้ที่ `css/tokens.css` ที่เดียว (สว่าง + มืด) โค้ด canvas อ่านค่าจาก CSS ทุกครึ่งวินาที (`js/core/colors.js`)

## ข้อมูลที่บันทึกในเครื่อง
`localStorage`: `slimerun-best` (สถิติสูงสุด), `slimerun-mute` (ปิดเสียง) — ชื่อคีย์อยู่ใน `config.js`

## เทสต์
`pip install playwright && playwright install chromium` แล้วรัน `python3 tests/smoke.py` (ตั้ง `CHROMIUM_PATH` ถ้าใช้ Chromium คนละที่)

## หนี้ทางเทคนิคที่รู้อยู่
- ตัวแปรสถานะเป็น global ร่วมกัน ถ้าจะแยกเป็น ES modules ต้องย้ายเข้า object เดียว (เช่น `Game.state`) และเสิร์ฟผ่านเซิร์ฟเวอร์
- ปิรามิด/หนวด (`summon()`) และฝนกระสุนยังผูกกับกลไกในไฟล์ boss.js
